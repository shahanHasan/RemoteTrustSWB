# Modeling References

These references guided the candidate model set used in this project.

- Sparse text benchmark (linear models / NB strength in high-dimensional text):
  - [scikit-learn: Classification of text documents using sparse features](https://sklearn.org/1.7/auto_examples/text/plot_document_classification_20newsgroups.html)
- Ensemble motivation for online recruitment fraud detection:
  - [ORFDetector (IEEE IC3 2019)](https://researchportal.hw.ac.uk/en/publications/orfdetector-ensemble-learning-based-online-recruitment-fraud-dete/)
- Soft-voting and probability support:
  - [scikit-learn VotingClassifier](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.VotingClassifier.html)
  - [scikit-learn calibration user guide](https://sklearn.org/stable/modules/calibration.html)
  - [scikit-learn CalibratedClassifierCV](https://sklearn.org/stable/modules/generated/sklearn.calibration.CalibratedClassifierCV.html)
- Class imbalance-friendly NB variant for text:
  - [scikit-learn ComplementNB](https://scikit-learn.org/stable/modules/generated/sklearn.naive_bayes.ComplementNB.html)
- EMSCAD framing:
  - [Future Internet (2017) EMSCAD paper](https://www.mdpi.com/1999-5903/9/1/6)
